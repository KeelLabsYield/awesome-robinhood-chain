# Submissions

Add one line at the end, in this format, and open a pull request:

```
- Project name — https://your-site.example — https://github.com/your-org/your-repo — what it does, in one sentence
```

Use your project's own official site and repository. A submission is a lead for Hey Research Lab's discovery, not a
listing: the project appears in the README once HEY verifies it from public evidence and it is shipping. Projects
already in the README do not need a line here.
