## Add your project

This list is generated, so a project joins it by being verifiable, not by a pull request to this file:

1. Make your project's public evidence readable: a public repository, a release or changelog feed, or a verified
   contract on the explorer, linked from your site.
2. Open a pull request adding one line to [SUBMISSIONS.md](SUBMISSIONS.md). The maintainers pass it to HEY's discovery.
3. Once HEY verifies it and it is shipping, the next weekly run lists it here.

Something wrong about an entry? Open an issue; the fix belongs in HEY's research, so every surface gets it.
