# Contributing

Thank you for helping map who is building on Robinhood Chain.

- **Add a project:** one line in [SUBMISSIONS.md](SUBMISSIONS.md), then a pull request. See the README's
  "Add your project".
- **Fix an entry:** open an issue naming the entry and what is wrong. The README is generated from Hey Research Lab's
  research, so the fix is made there and every surface gets it; please do not edit the generated sections by hand.
- **Improve the list itself:** changes to `template.md`, `scripts/generate.mjs` or the workflow are welcome. Run
  `node scripts/generate.mjs` (Node 20+, no dependencies) and include the regenerated README.

Issues labelled [good first issue](https://github.com/hey-research-lab/awesome-robinhood-chain/labels/good%20first%20issue)
are small and well described. During Hacktoberfest, merged pull requests are labelled `hacktoberfest-accepted`.

Be kind; review comments are about the change, never the person.
